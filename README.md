# Student Course Management System

A Java-based application for managing students, courses, and their enrollments. This system provides functionality for tracking student information, course details, and course registrations.

## Features

- **Student Management**: Add, view, and manage student information
- **Course Management**: Create and manage course offerings
- **Course Enrollment**: Register students for courses and track enrollments
- **Data Persistence**: Store and retrieve data efficiently

## Requirements

- Java 8 or higher
- Maven (for building and dependency management)

## Getting Started

### Prerequisites

Ensure you have Java and Maven installed on your system.

### Building

```bash
mvn clean compile
```

### Running

```bash
mvn exec:java
```

### Testing

```bash
mvn test
```
